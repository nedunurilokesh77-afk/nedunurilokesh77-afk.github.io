# Deploy the updated ECE portfolio to GitHub Pages

1. Extract this ZIP.
2. Open the GitHub repository that currently publishes your portfolio.
3. Back up the current repository contents.
4. Upload/replace the files and folders from this ZIP at the repository root. Keep the existing repository name and publishing settings.
5. Commit the changes to the branch configured under **Settings → Pages** (usually `main`, `/ (root)`).
6. Wait for the GitHub Pages deployment to complete, then open the live site and check the profile photo, navigation, sections and contact links.

## Google Search Console

The project retains the existing Google site-verification meta tag and verification HTML file. Do not delete either unless Search Console confirms another active verification method.

After the updated site is live:

1. Open Google Search Console and select the verified property for `https://nedunurilokesh77-afk.github.io/`.
2. Open **Sitemaps** and submit `sitemap.xml`.
3. Open **URL Inspection**, enter `https://nedunurilokesh77-afk.github.io/`, run **Test Live URL**, then choose **Request Indexing** if the live page is accessible.
4. Also inspect the profile photo and social preview image URLs after deployment.

Google controls crawling, indexing, snippets and ranking. SEO metadata and a sitemap help search engines understand and discover the site, but they cannot guarantee a particular ranking or instant appearance in search results.
